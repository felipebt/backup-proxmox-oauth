Política de Privacidade

A aplicação Backup Proxmox é utilizada exclusivamente para realizar backups internos dos servidores da BL Importadora no Google Drive.

Dados acessados

A aplicação utiliza a API do Google Drive para criar, consultar, enviar e excluir arquivos relacionados aos backups dos servidores.

Uso dos dados

Os dados acessados são utilizados exclusivamente para execução, verificação e retenção dos backups da infraestrutura da empresa.

Nenhum dado obtido através das APIs do Google é vendido, compartilhado com terceiros ou utilizado para publicidade.

Armazenamento das credenciais

As credenciais de autenticação são armazenadas localmente no servidor responsável pelos backups e são utilizadas apenas pelo software rclone.

Revogação de acesso

O acesso pode ser revogado a qualquer momento através das configurações de segurança da Conta Google utilizada para os backups.
